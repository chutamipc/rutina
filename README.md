# rutina

Página personal de entrenamiento y dieta (definición), hecha para el celular.

- Un solo archivo, `index.html`: HTML, CSS y JS adentro, sin frameworks ni build.
- El plan (fechas, calorías, ejercicios, comidas) está en el bloque `PLAN - CAMBIAR AQUI` del script.
- Lo que se anota (pesos, medidas, checks) se guarda solo en el navegador del celular (`localStorage`, clave `rutina-v1`). No se sube a GitHub. Respaldo: Progreso → Tus datos → Exportar respaldo.
- Para probar otra fecha: agregar `?fecha=2026-12-01` a la URL.
